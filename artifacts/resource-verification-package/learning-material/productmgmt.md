## Stage 2 — User Research & Discovery

**Objective:** Run honest discovery before writing requirements.

**Success criteria:**
- Run good interviews
- Avoid leading questions
- Map assumptions

### Instruction

The biggest PM mistake is building solutions before understanding problems. Discovery is how you earn the right to write a PRD.

OBJECTIVE
Run honest discovery before writing requirements.

SUCCESS CRITERIA
• Run good interviews
• Avoid leading questions
• Map assumptions

WORKED EXAMPLE
Conduct user research. Step 1: write five open questions about behaviour, not opinions. Step 2: interview three people from the target segment. Step 3: capture verbatim quotes and observed workarounds. Step 4: synthesise into two or three insights, each tied to a quote.

COMMON MISTAKES
• Asking about hypotheticals instead of past behaviour
• Pitching instead of listening
