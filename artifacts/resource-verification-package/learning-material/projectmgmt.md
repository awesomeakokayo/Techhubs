## Stage 5 — Budgeting & Reporting

**Objective:** Report cost and schedule health honestly.

**Success criteria:**
- Forecast a budget
- Interpret EVM
- Write a useful status report

### Instruction

Numbers and communication are what separate junior PMs from senior ones. Learn to tell the truth about project health clearly and early.

OBJECTIVE
Report cost and schedule health honestly.

SUCCESS CRITERIA
• Forecast a budget
• Interpret EVM
• Write a useful status report

WORKED EXAMPLE
Report project status. Step 1: build a budget with categories and a variance tracker. Step 2: compute earned value (PV, EV, AC) and the cost/schedule indices. Step 3: write a one-page status with the top risks. Step 4: state the decisions you need from the sponsor, not just the numbers.

COMMON MISTAKES
• Reporting activity instead of progress against plan
• Hiding bad news until it is too late

### Worked example

Report project status. Step 1: build a budget with categories and a variance tracker. Step 2: compute earned value (PV, EV, AC) and the cost/schedule indices. Step 3: write a one-page status with the top risks. Step 4: state the decisions you need from the sponsor, not just the numbers.

### Common mistakes
- Reporting activity instead of progress against plan
- Hiding bad news until it is too late
