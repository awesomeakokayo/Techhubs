   `ProjectBrief` interface (`lib/curriculum.ts` has `objective`, `problem`,

   required evidence**. Section 7 now renders Objective, Problem, Audience,
   Required functionality, Acceptance criteria, **Required evidence** and
   Constraints. Verified: 0 empty bullets; **110 "Required evidence" blocks**.

   packet: the per-track thresholds, mandatory gates, per-stage resource/quiz/
   rubric/project requirements, the human sign-off requirement, and an explicit
   "would fail review if…" list. Verified present in all 32 packets.

instruction, resource evidence with excerpts and limitations, knowledge checks
