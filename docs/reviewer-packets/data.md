## 5. Knowledge checks and answer keys (internal)

### Stage 1 — Spreadsheets & Excel (3 questions)

1. Which function looks a value up in another table?
   - · SUM
   - **✔ VLOOKUP**
   - · COUNT
   - · IF
   - _Why:_ VLOOKUP finds a value in a table by matching a key; INDEX/MATCH is more flexible. · _level: recall_
2. What is a pivot table for?
   - · Storing raw data
   - **✔ Summarising and grouping data interactively**
   - · Formatting cells
   - · Encrypting a workbook
   - _Why:_ Pivot tables aggregate and group data for analysis. · _level: understand_
3. A bar chart starts its y-axis at 80 instead of 0. What is the risk?
   - · None
   - **✔ It exaggerates small differences and can mislead**
   - · It improves accuracy
   - · It is required by Excel
   - _Why:_ A truncated axis can visually exaggerate differences. · _level: evaluate_

### Stage 2 — SQL Fundamentals (3 questions)

1. Which clause filters groups produced by GROUP BY?
   - · WHERE
   - **✔ HAVING**
   - · ORDER BY
   - · LIMIT
   - _Why:_ HAVING filters after aggregation; WHERE filters rows before grouping. · _level: understand_
2. You need every customer, even those with no orders. Which join?
   - · INNER JOIN
   - **✔ LEFT JOIN**
   - · CROSS JOIN
   - · FULL OUTER JOIN only
   - _Why:_ LEFT JOIN preserves all left-side rows, including customers with no matching orders. · _level: apply_
3. Which window function assigns a rank within each group?
   - · SUM()
   - **✔ ROW_NUMBER() OVER (PARTITION BY ... ORDER BY ...)**
   - · COUNT(*)
   - · AVG()
   - _Why:_ ROW_NUMBER with PARTITION BY ranks rows within each group. · _level: apply_

### Stage 3 — Python for Data (3 questions)

1. Which pandas structure is a two-dimensional labelled table?
   - · Series
   - **✔ DataFrame**
   - · ndarray
   - · Index
   - _Why:_ A DataFrame is a 2D labelled data structure. · _level: recall_
2. What does df.groupby("region")["sales"].sum() return?
   - · A single number
   - **✔ Total sales per region**
   - · The whole table
   - · An error
   - _Why:_ It groups by region and sums sales for each group. · _level: apply_
3. Before dropping rows with missing values, what should you check?
   - · The column colours
   - **✔ How many rows are affected and whether the missingness is biased**
   - · The file size
   - · The index type
   - _Why:_ Dropping can bias the analysis; understand the missingness first. · _level: evaluate_

### Stage 4 — BI & Visualization Tools (3 questions)

1. Which chart best shows a trend over time?
   - · Pie chart
   - **✔ Line chart**
   - · Scatter plot
   - · Gauge
   - _Why:_ Line charts show trends over time clearly. · _level: apply_
2. What is the most important element of a dashboard?
   - · The number of charts
   - **✔ A clear takeaway or focal metric**
   - · Bright colours
   - · Animation
   - _Why:_ A dashboard should communicate a clear message, not display everything. · _level: evaluate_
3. When is a pie chart a poor choice?
   - · For two categories
   - **✔ When there are many categories with similar values**
   - · For percentages summing to 100
   - · Never
   - _Why:_ Many similar slices are hard to compare; use a bar chart instead. · _level: analyze_

### Stage 5 — Statistics Basics (3 questions)

1. When is the median preferred over the mean?
   - · When data is symmetric
   - **✔ When data is skewed or has outliers**
   - · Never
   - · Only for two values
   - _Why:_ The median is robust to outliers and skew. · _level: apply_
2. Ice cream sales and drowning incidents rise together. What is the correct conclusion?
   - · Ice cream causes drowning
   - **✔ A third factor such as warm weather likely explains both**
   - · Drowning causes ice cream sales
   - · The data is wrong
   - _Why:_ Correlation does not imply causation; a confounder is likely. · _level: evaluate_
3. A p-value of 0.03 means…
   - · There is a 3% chance the hypothesis is true
   - **✔ Assuming the null hypothesis, results this extreme are unlikely (3%)**
   - · The effect is large
   - · The study is proven
   - _Why:_ A p-value is the probability of the data under the null hypothesis, not the probability the hypothesis is true. · _level: analyze_
